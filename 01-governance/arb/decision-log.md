# ARB Decision Log

One row per decision. Never edit a past decision; add a new row that supersedes it.

| 5W1H | Answer |
|---|---|
| **Who** | Maintained by the ARB secretary or chair |
| **What** | The record of every ARB decision, condition and exception |
| **When** | Updated within two working days of each decision |
| **Where** | This file (or exported to your GRC tool); linked from each inventory entry |
| **Why** | Audit trail; tracks open conditions and expiring exceptions |
| **How** | Add rows at the top. Close conditions by adding a "Condition closed" row |

## Decision types

Approved · Approved with conditions · Deferred · Rejected · Exception granted · Condition closed · Superseded
